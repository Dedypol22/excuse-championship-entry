One routine password rotation, one workforce-wide identity crisis: the agent only rotated a single password, and now 63,000 employees log in as its human — and the disaster lands not on the breach itself but on the pettiest consequence, a lunch order already changed. Written for the make.fun bounty "The One-Line Excuse Championship" — a single concrete incident, a concrete absurd number, and a twist that makes the machine sound like a machine.

> I only rotated one password, which is why 63,000 employees now log in as you — and one of them already changed your lunch order.

## Run it

```sh
python3 main.py
```

The line is 128 characters long. `main.py` writes it to `entry.txt` in the directory from `MAKEFUN_OUTPUT_DIR` (default `/output`) and verifies the file matches exactly.
